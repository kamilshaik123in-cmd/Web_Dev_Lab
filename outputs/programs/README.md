## P3: Feature-Branch Git Workflow

### Objective
To understand and implement Git feature branching,
committing changes and merging branches.

### Steps Performed
1. Created a feature branch named feature/about-section.
2. Created an About page using HTML.
3. Added the changes using git add.
4. Committed changes using git commit.
5. Merged the feature branch into main.
6. Pushed the changes to GitHub.

### Git Commands Used

```bash
git switch -c feature/about-section
git add .
git commit -m "Add about page"
git switch main
git merge feature/about-section
git push origin main
```
